Get it running

Three steps, no store required.

1

Allow unknown sources

In Settings → Apps, let your browser or Files app install unknown apps. Android will ask again on first install — that's expected.

2

Download the APK

Grab the latest build from the button above. It's a single file, no installer wizard.

3

Install & open

Tap the downloaded file, confirm the install, and launch VinMusic.
